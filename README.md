# Streamlining-Data-Reporting-Processes
End-to-end ETL and analytics pipeline that centralizes Morningstar fund data (returns, volatility, exposures, holdings) into tidy datasets and Power BI-ready metrics. Enforces no look-ahead; computes absolute/relative performance (Sharpe, TE, beta, drawdown) across windows; snapshots, back-fills history, and validates schema.
